# Refresh the profile

`README.md`, the banner, and the project chart are generated by `sync_portfolio.py`.
The canonical content is `Metaphysicist1/ultra-portfolio/public/data/life.json`.

```sh
python3 -m pip install -r scripts/requirements.txt
python3 scripts/sync_portfolio.py
git diff
```

The script resolves the source repository's main branch to a commit before fetching
data and project screenshots. `data/source.json` records that commit and the JSON
checksum. It does not commit or push. Review the result before publishing.

For reproducible offline regeneration from the checked-in data and screenshots:

```sh
python3 scripts/sync_portfolio.py --offline
```

The chart counts the 11 project IDs in `PROJECTS`, grouped by the dates recorded in
the source. It excludes other milestones. Add new project IDs there when extending
the selection. Featured projects, experience copy, and layout are curated in the
script; review those when the portfolio changes. Images are repository assets;
there are no external statistics widgets, tracking badges, or runtime dependencies.
