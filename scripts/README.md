# Refresh the profile

`README.md` and `assets/board/` are generated by `sync_portfolio.py`.
The words and project links come from `Metaphysicist1/ultra-portfolio/public/data/life.json`.
The contribution city, language bar and counters come from `data/github.json`.

```sh
python3 -m pip install -r scripts/requirements.txt
python3 scripts/sync_portfolio.py
git diff
```

The script resolves the source repository's main branch to a commit before fetching
data and project screenshots. `data/source.json` records that commit and the JSON
checksum. When `gh` is logged in it also refreshes the public GitHub snapshot.
It does not commit or push.

For reproducible offline regeneration from the checked-in data:

```sh
python3 scripts/sync_portfolio.py --offline
```

Jupyter notebooks are left out of the language bar. Their byte count is mostly
saved output, not code.

The streak and the activity graph are external images, fetched through GitHub's
image proxy, and can have outages or cached data. The drawn board does not
depend on them. There are no visitor counters or tracking pixels.
